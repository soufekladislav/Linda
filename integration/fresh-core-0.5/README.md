# Fresh Core 0.5.2 integration reference

This folder is a reference copy of the universal content/commerce bridge used by Linda. Do **not** install it as a separate plugin.

For deployment use the complete `fresh-core-0.5.2` plugin package delivered together with Linda 0.4.4. The API stays generic for Linda, Boban, Web Booster and future Fresh employees.

Read routes include content export, URL preview/status, analytics summary and WooCommerce commerce catalog/product detail. Protected write routes include generic content upsert and SEO writes.
